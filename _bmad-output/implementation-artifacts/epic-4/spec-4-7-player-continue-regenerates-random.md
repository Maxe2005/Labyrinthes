# Story 4.7: Player — Continue regenerates a random maze with the same params

Status: done

## Story

As a player,
I want the win banner's "Continue" action to immediately generate a new random maze with the same dimensions and entry position when I just solved a generated maze,
So that I can keep playing without reconfiguring.

## Acceptance Criteria

1. **Given** a `generated` maze (kind=`generated`, no `MazeId`) was just solved and the win banner appears, **when** the player clicks "Continue", **then** a new random maze is generated with the same width, height, and entry position, and the gameplay screen remounts with it immediately.

2. **Given** a `classic` or `saved-random` maze was just solved and the win banner appears, **when** the player clicks "Continue", **then** the existing Continue behavior applies (restart the same maze or return to selection — unchanged from Epic 2).

3. **Given** the new maze generated by Continue, **when** it is produced, **then** its kind is `generated` (not `saved-random`) with no `MazeId`.

4. **Given** the win banner UI, **when** the maze kind is `generated`, **then** the Continue button's tooltip or label reflects "New random maze" (or similar) to indicate the regeneration behavior.
